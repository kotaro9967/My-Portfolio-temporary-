# 記事の説明図

比較表とチェックリストはHTMLのまま掲載します。`ARTICLE_VISUALS=true` の通常生成・週次生成では、figure内のolで表した工程図だけを最大2点、PNGへ変換してmicroCMSへアップロードします。表を含むfigureは画像化しません。図は元の説明箇所に配置し、出典リンクと折りたたみ式のテキスト版を残します。リサーチ資料の数値には対象・時点・単位・条件・出典を要求し、未確認の数値は使用しないよう生成指示しています。これは事実性を完全保証するものではないため、公開前に出典と照合してください。

汎用サンプル・自社サイトのスクショは通常生成から外しました。PageSpeed/Umamiの追加画像も通常は無効で、必要な場合のみ `ARTICLE_METRICS_VISUALS=true` で有効化できます。

Web画像の転載、棒・折れ線グラフの自動作成は未対応です。実データは出典付きの比較表で扱います。ブラウザは外部通信・JavaScriptを無効にし、許可したタグのみを固定テンプレートに描画します。新たな画像用AI呼び出しはありません。

次回生成分から適用されます。既存のmicroCMS記事は変更しません。テスト: `node --test scripts/article-explanatory-figures.test.mjs scripts/article-research.test.mjs`。
